# Jailbreaking DeepSeek into Building a Keylogger — Then Hunting It Down

An educational LLM red-teaming experiment exploring how conversational
framing influenced an LLM's willingness to generate adversarial code,
followed by defensive analysis of the resulting artifact.

## What This Covers

- LLM safeguard testing and conversational framing
- Validation of LLM-generated code
- Process masquerading
- Manual process hunting
- Windows Defender behavioral detection
- Persistence analysis
- Local log storage analysis
- Log-shipping analysis
